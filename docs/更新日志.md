### 修复 | 静态页点站内链接只换地址不换内容

- `interceptLinks()` 把所有同源 `<a>` 都当站内路由：`preventDefault()` 之后 `pushState("/changelog")`，再重绘正文。可这页是静态文档（`.app[data-static]`），`applyRoute()` 一见这个标记直接 return——地址变了、正文还停在首页那套卡片流，得手动刷新一次。
- 反向一样坏：从更新日志页点任何导航，也是 `pushState` 完原地不动。
- 改法：加 `var STATIC_PAGES = ["changelog"]`；`interceptLinks` 里两道判断（当前页是静态文档、目标页在清单里，都放在 `preventDefault` 之前直接 return）；`applyRoute()` 补一条，老书签 `/#/changelog` 直接 `location.replace` 到真实路径。
- 全站只有 changelog 一个静态文档。`post.html`、`admin.html`、`404.html` 没有 `.app` 容器，从来没被拦截；`/feed.xml` 只出现在 `<link rel="alternate">` 里。以后再加静态页，往那个清单里添个名字。

### 基建 | 农历库 443KB 改闲时取，写作页与文章页终于有农历

- `lunar.js` 从 `defer` 列表里摘掉，改由 main.js 在 `requestIdleCallback` 里取（没有这个 API 就 1.5s 后），取到回调 `__rezeRepaintCal()` 重画日历；取不到只显示公历，别的照旧。
- 版本号从 main.js 自己的 `src` 上抠 `?v=`，这样 `bump_version` 只改 HTML 也跟得上。
- 顺带修好一个老问题：以前只有 index.html 引了 lunar.js，`/writing` 和文章页的日历从来没显示过农历。

### 基建 | 背景图全部转 WebP，八张省下 940KB

- 新增四张 2560×1600 的公开照片（Unsplash），与原来四张凑成八张；`homeBgs` 在 data.js、data.meta.js、data.override.js 与云端 settings 四处同步，漏一处就会出现「本地有、线上没有」。
- 八张统一转 WebP（q74、method=6）：2018KB → 1078KB，省 940KB，减 47%。旧的四张 `bg1`／`bg3`／`bg`／`bg5` 一并换掉，全仓只有 `homeBgs` 与 data.js 的 `bg:` 字段引用过它们。
- 云端 `settings.homeBgs` 改成 `.webp` 后缀。`POST /site-data/settings` 是整存，改前落了快照，改后 GET 回来逐项比对，只有 `homeBgs` 一个键变了。

### 基建 | 首屏不再白下八张背景图

- 设置面板的背景缩略图在页面挂载时就建八个 `<img>`，面板本身 `display:none`，`loading="lazy"` 在隐藏容器里不生效——等于每次进站白下七张原图，约 900KB。改成打开面板时才调 `paintBgRow()`，日志里只剩当前生效那一张的请求。
- 首页那段「尽早恢复记忆中的背景」的内联脚本写死了四张图的数组，背景加到八张之后，索引 4–7 的用户等于没有预加载。改读 `reze-bg-url`：背景真正铺上去时由 `applyPageBg()` 写进这个键，随机模式不写，否则下次进站会先闪一张旧图。

### 界面 | 背景亮度改成真亮度，撤掉整页白幕

- 原来是给整页盖一层白幕（`--lite`），只把画面对比压平，看着像蒙了一层布，滑块推到头也不亮。
- 改用 `.page-bg { filter: brightness(var(--bg-bright, 1)) }`，滑块 40%–160%、默认 100，白幕默认归零停用。存储键从 `reze-lite` 换成 `reze-bg-bright`，旧键不迁移。

### 修复 | 卡片变透明：装饰色条抢了底衬的伪元素

- 背景换成浅色照片后卡片看着像没上底，起初当成玻璃变量与背景亮度的问题，调了两轮没用。
- 真因是伪元素重名：底衬挂在 `.card::before`（`inset:0` 加 `rgba(--card-tint, --card-alpha)`），无封面卡左侧那道 3px 分类色条也写成 `::before`，后定义的赢，底衬只剩 3px 宽。用 `getComputedStyle(el, "::before")` 把尺寸打出来才看见。
- 色条改挂 `::after`，把 `::before` 还给底衬。滑块下限 0 → 70、默认 66 → 74，读回的旧值低于 70 的一律抬到 70 再回写。

### 界面 | 删掉封面占位图，无封面改纯文字卡

- 没有封面的文章原来用色块加首字当占位，八个色相轮着来，看着像图没加载出来。删掉 `phInner()`／`coverHue()` 与 `.cover.ph` 三套样式，有 `cover` 才出 `<img>`，没有就留空。
- 列表卡网格默认 `1fr 236px`，无封面时收成 `1fr`，标题不再留半张空白；「今日一组」与文章头图同理。
- 补几处克制的细节：分类小标做成淡色块、无封面卡左侧一道 3px 色线（就是上一节抢底衬的那道）、文章标题下一段 44px 短色条。色相由 JS 注入 `--cat-h`，CSS 只管用。

### 界面 | 浅色主题重做：撤掉整页白幕，卡片材质与浓度可调

- 白是三层叠出来的：卡片底衬 82%、卡片本体 34% 玻璃、`html::after` 12% 白幕。白幕压在字上，想调亮只能继续加白，方向从一开始就反了。
- 改法：背景加一层纸面纱（`--veil-alpha`），插画退成纹理；卡片只留 `rgba(--card-tint, --card-alpha)` 一个色源，基色换成纸白 255,253,248；卡片与页面的分界交给一条 10% 墨的细线。
- 浅色下 `--lite` 归零，白幕停用。
- 设置面板加四个开关：卡片材质（纯色／半透明／毛玻璃）、浓度、颜色（纸白／纯白／暖米／冷灰）、背景弱化。切换材质时把浓度同步成该材质的默认值，否则看不出按钮起没起效。
- 踩到的坑：把 `--card-scrim` 本身改成嵌套 var，页面看着全对，`player_contrast.js` 却一行都算不出来——嵌套 var 解析不了。改成覆盖 `::before` 的 `background`，变量保持字面值，审计恢复。
