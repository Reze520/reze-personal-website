<p>这个站我改了很多遍。最开始那一版现在看挺难看的，主要问题是挤。</p>
<p>那时候我的想法是，页面上不能空着。空着就像没做完。所以每个板块我都加了边框，内容之间只留一点点缝，颜色也换了好几个，想让它看起来满一点。</p>
<p>现在回想，「不能空着」这个念头其实跟审美没什么关系，它更像一种焦虑。当时我刚把这个站弄起来，心里觉得它太单薄——内容不多，功能也不多，所以只能靠视觉上的密度去补。留白在那时候对我来说不是设计，是「没什么可放的」。</p>
<p>所以加边框还有一个作用：让每一块都显得有边界、有归属。哪怕里面只有两行字。</p>
<p>自己看不出来。后来有天在手机上看，看两分钟就觉得累，往下翻的时候眼睛找不到落点。</p>
<p>「找不到落点」这个描述我后来一直记着。它不是看不清，是眼睛不知道往哪儿停。屏幕上每一块都画着框，每条缝都一样宽，人眼没有一个可以歇的地方，只能一直滑下去。滑久了就很累，而且滑到哪儿都没记住。</p>
<h2>空的地方不是浪费</h2>
<p>以前我以为空白就是没东西。现在觉得它更像隔开。</p>
<p>两块内容中间留够了，人自己就知道它们不是一回事，不用再画线。我原来加那么多边框，其实是在补这个没留够的距离。</p>
<p>这个先后关系很关键：边框和间距干的是同一件事，都是用「隔开」来表现「这是两回事」。如果间距已经够了，边框是多余的；如果间距不够，加再多边框也只是画了更多线，两块东西还是粘在一起。</p>
<p>道理说穿了很简单，但真改的时候我才发现，我根本不会量。我调间距全靠感觉，8、10、12、15，看哪个顺眼用哪个。所以怎么调都有一种说不出的乱。我还以为是颜色的问题，换了好几遍颜色，一点用都没有。</p>
<p>这段经历当时挺打击人的。因为我确实调了很久，每天改一点，改完自己看着还行，第二天再看又不对。换颜色、换字体、换圆角，全都试过。每次改完都有一段短暂的满意期，过一天就消失。</p>
<p>现在我知道问题出在哪：我改的每一项都是「单个元素」，但看着乱是「很多元素之间」的关系问题。只调单个元素，永远碰不到那个关系。</p>
<h2>后来只用几个数</h2>
<p>4、8、16、24、40、64，就这几个，别的不用。想拉开一点就往上跳一档，不要自己造一个 13 出来。</p>
<pre><code>.gap-1 { margin-bottom: 4px; }
.gap-2 { margin-bottom: 8px; }
.gap-3 { margin-bottom: 16px; }
.gap-4 { margin-bottom: 24px; }
.gap-5 { margin-bottom: 40px; }</code></pre>
<p>一开始很别扭，因为有时候我就想要 12 像素，差 4 像素我觉得肯定能看出来。用久了才发现人眼其实分不清，但能感觉出来这些间距是不是一家的。</p>
<p>这句话我想展开一点：人眼分不清 12 和 16，但能分辨出「这里有 12 和 15」和「这里全是同类数」。前者的乱是被感知到的，不是被看清的。所以限制数字的价值不在于精确，而在于减少了可能互相冲突的组合。</p>
<p>这套数还有个好处，是它自己就带着节奏。8 和 16 之间是两倍关系，16 和 24 之间是一倍半，这种关系让页面在视觉上有一个可以预期的层级。如果每个间距都是随机数，那每一块都是独立的一块，读的人得重新判断一次。</p>
<p>我后来把这条用在了别的地方，比如字号、圆角、行高，都收敛到几个固定值。第一次改完，那种「说不出的乱」真的消失了。但同时也带来一个新问题：页面变得有点平，因为没法再用一个精细的数字去做局部的强调。这个问题我到现在也没完全解决，只能靠别的手段，比如加粗、换色。</p>
<h2>字重比字号好用</h2>
<p>这个是看别人的站学的。我以前要强调什么就把字放大，结果一页里四五种字号，看着乱。</p>
<p>放大的问题在于它会挤乱版面。字一变大，行高、间距、换行全跟着变，一块内容撑起来一点，后面的东西就都要往下挪。而且同一页里出现几种字号之后，读者会不自觉地想「这么大的字是什么意思」，但这个层级往往是我随手定的，并没有真的含义。</p>
<p>现在标题和正文一样大，只把字重加粗、颜色加深。层次出来了，页面也安静不少。</p>
<p>安静这个词是我自己感受出来的，说不出太多道理。大概是因为字号统一之后，文字的「骨架」是一样的，变动的只有重量，看起来更像同一套东西。而字号不同，视觉上像换了一种字体，页面就碎。</p>
<p>不过这条也有例外。文章页的大标题我最后还是放大了一点，因为它需要把整个页面「先定住」。我现在的标准是：一页里最多两处字号变化，而且必须是真的层级，不是装饰。</p>
<h2>回头看那版，我到底舍不得什么</h2>
<p>有件事我后来才想清楚。我当初那么怕空，是因为我觉得留白会让人一眼看出这个站内容少。其实正相反——挤满才更容易露馅，因为每块都得有边框撑着，说明里面的东西自己站不住。</p>
<p>留白其实是在给内容让位。内容够硬的时候，周围的空白会让它看起来更硬。</p>
<p>现在看，还是觉得有些地方挤，有些地方空落落的。这事好像没有做完的时候，隔几天看总能挑出新的毛病。</p>
<p>我也慢慢接受了这种状态。以前我会觉得改不好是因为水平不行，现在觉得它更像一件一直在动的事——你的眼睛在变，看同一份东西的标准也在变。今天满意的页面，半年后看一定会有想改的地方，那不是失败，那是眼睛变好了。</p>
