# 从「域名实名完成」到「网站能访问」的完整步骤

> 域名实名通过只是第一步。要让 `reze520.top` 真正打开你的网站，
> 还需要 **一台国内服务器** 和 **ICP 备案号**，两个都缺一不可。
> 整体时间：**约 2～4 周**，其中大部分时间在等备案审核。

---

## 先看清全貌

```
✅ 买域名          已完成
✅ 域名实名        已完成（1-3 天）
⬜ 买服务器        今天就能做
⬜ 提交 ICP 备案   买完服务器立刻能提交
⬜ 等审核          7～20 个工作日（期间网站不能访问）
⬜ 解析域名 + 传文件 + 开 HTTPS   备案通过后半天搞定
```

**为什么必须备案？** 因为服务器在中国大陆。工信部规定，域名指向大陆服务器必须备案，
否则运营商会拦截 80/443 端口，域名打不开。这不是阿里云的规定，是国家规定。

---

## 第一步：买服务器（约 10 分钟）

阿里云控制台 → **轻量应用服务器** → 创建。

| 选项 | 选什么 | 为什么 |
| --- | --- | --- |
| 地域 | 离你近的（如杭州、上海） | 备案要在服务器所在地管局，选近的审核快 |
| 镜像 | **Ubuntu 22.04** 或 **宝塔面板** 镜像 | 宝塔镜像自带图形面板，新手友好 |
| 配置 | 2 核 2G 起步 | 静态站 1 核 1G 都够，2G 是给系统留余量 |
| 时长 | **至少 3 个月，建议 1 年** | 备案要求服务器剩余时长 ≥ 3 个月，买短期会被打回 |
| 带宽 | 3M 起步 | 静态站流量很小，3M 足够几十人同时看 |

> **别买香港或海外节点**——海外服务器不需要备案，但也就不存在「转到国内域名」这回事了，
> 而且国内访问会慢。你既然要备案，就买大陆节点。

买完记下：**公网 IP**、**root 密码**。

---

## 第二步：拿「备案服务码」（2 分钟）

阿里云控制台 → 搜索「**备案**」→ 进入 ICP 代备案系统 → 左侧「**备案服务码**」→ 点「申请」。

服务码是备案的入场券，每台服务器一般给 5 个，一个网站用一个。

---

## 第三步：提交备案（约 30 分钟填资料）

同一个页面 → 「**开始备案**」。需要准备：

- 身份证正反面照片（拍清楚，四角完整）
- 本人手机号（要能接电话、收验证码）
- 人脸核验（阿里云 App 里做，跟着提示转头眨眼）

### 填写要点（这里最容易被打回）

| 字段 | 怎么填 | 说明 |
| --- | --- | --- |
| 网站名称 | **蕾泽的小站** / **蕾泽的个人博客** | ⚠️ **不要**单独写「个人博客」「我的网站」「技术博客」——太宽泛，管局会打回要求改名 |
| 网站内容 | 个人生活记录、学习笔记 | 不要写「论坛」「社区」「商城」「资讯」——那属于需要前置审批的类型 |
| 服务内容 | 其他 / 博客 | 个人备案不能有评论、不能有付费、不能有广告 |
| 备注 | 记录自己的生活和学习，非商业用途 | 一句话说清楚 |

> **个人备案的红线**：不能有经营性内容、不能有用户注册和评论功能、不能放广告。
> 你这个站目前完全符合——没有评论、没有登录、没有广告。**保持这样**。

---

## 第四步：等审核（7～20 个工作日）

流程是：阿里云初审（1-2 天）→ 短信核验 → **管局审核**（7-20 天）。

三件事必须注意：

1. **一定要接电话**。管局或阿里云可能会打你手机核实「是不是你本人备案的」，漏接会被打回重来。
2. **备案期间域名不能访问**。所以这期间千万别急着把站挂上去，也别解析。
3. **随时看短信**。需要补材料会在 24 小时内通知，超时作废。

审核通过后，你会收到一条短信，里面有一串 `X ICP 备 XXXXXXXXXX 号-X`。

---

## 第五步：备案通过后，部署（半天）

### 1. 解析域名

阿里云控制台 → 域名 → 解析设置 → 添加记录：

| 记录类型 | 主机记录 | 记录值 |
| --- | --- | --- |
| A | `@` | 你的服务器公网 IP |
| A | `www` | 你的服务器公网 IP |

十分钟左右生效。可以在这个网站查：`ping reze520.top`，能返回你的 IP 就通了。

### 2. 把网站传上去

**如果装了宝塔面板**（推荐，全图形化）：

1. 浏览器打开 `http://你的IP:8888`，用面板给的账号密码登录
2. 左侧「网站」→「添加站点」→ 域名填 `reze520.top` 和 `www.reze520.top`
3. 进入站点目录，把 `reze-blog` 里的**全部文件**上传进去（不要上传 `reze-blog` 这个文件夹本身，要里面的内容）
4. 左侧「网站」→ 点站点 →「SSL」→「Let's Encrypt」→ 勾选域名 → 申请
5. 打开「强制 HTTPS」

**如果用命令行**：

```bash
# 在本机执行（Windows 用 Git Bash 或 PowerShell）
scp -r ./reze-blog/* root@你的IP:/var/www/reze/

# 在服务器上执行
apt update && apt install -y nginx
# 把 deploy/nginx.conf 传到 /etc/nginx/sites-available/reze
ln -s /etc/nginx/sites-available/reze /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

### 3. 上传后必须做的一件事

打开 `assets/js/data.js`，把这一行改成真实备案号：

```js
icp: "苏ICP备2026xxxxxx号-1",
```

**国家规定备案号必须显示在网站底部**，你现在的页脚已经留好位置了，改这一个字段全站自动显示。

### 4. 开 HTTPS

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d reze520.top -d www.reze520.top
```

跟着提示输入邮箱、同意协议，它会自动改 Nginx 配置。证书 90 天自动续，不用管。

## 常见问题

**Q：备案期间网站完全不能开吗？**
是的。管局会抽查域名，能打开但没备案会被驳回。这段时间安心改样式、写文章。

**Q：能不备案吗？**
可以，但只能用境外服务器（香港、新加坡）。国内访问会慢，而且有些网络环境打不开。
你的域名是 `.top` 的国内实名域名，走备案才是正路。

**Q：备案被打回怎么办？**
最常见原因是「网站名称太宽泛」或「服务内容写了敏感词」。按上面的表格改，重新提交即可，不用重新买服务器。

**Q：服务器到期了会怎样？**
备案会被注销。所以到期前记得续费，建议一次买 1-3 年。

**Q：想先让朋友看看，有办法吗？**
有，但别用域名。直接传文件让对方本地打开，或者用免费的临时托管（Cloudflare Pages 之类，
不用备案，但访问地址是 `xxx.pages.dev` 这种，不是你的域名）。
