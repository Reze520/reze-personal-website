在线工具箱

十七个平时会顺手用到的小工具，点上面的标签切换。都是我自己写的，纯前端实现，计算全在浏览器里完成，输入的内容不会上传到云端，也不需要登录或安装。

纯前端 · 零依赖 · 断网也能用

文本统计与整理

粘贴一段文字，先看统计，再按需要处理。结果写在下面，原文不动；想接着处理可以写回输入框。

编码转换

Base64、URL、Unicode 转义、HTML 实体。中文按 UTF-8 处理，不会乱码。

时间戳转换

秒和毫秒自动识别。日期按你电脑的本地时区换算，同时给出 UTC。

—
—
—

JSON 格式化

格式化、压缩、校验。解析失败会告诉你大概在第几个字符出错。

正则测试

边写边看匹配结果。表达式不用写两边的斜杠，标志按需勾选，最多列出 200 处匹配。

—
—
—

文本对比

按行比较两段文本，绿色是新增、红色是删除。两边加起来最多处理 500 行。

—

密码生成

用浏览器自带的加密随机数生成，不联网、不记录，也不会用 Math.random 凑数。

—

颜色转换

输入 HEX、RGB 或 HSL 任意一种，另外两种自动算出。也可以直接用取色器挑。

单位换算

长度、重量、温度、数据存储、速度、时间。改动数值或单位即时出结果；存储按 1 KB = 1024 B 计算。

—

文件哈希

在本地算出文件的 SHA 校验值，用来比对下载是否完整。文件不会上传；计算时会一次性读入内存，建议 200 MB 以内。

图片压缩

在本地把图片重新编码，可调质量和最大宽度，直接下载。原图不会改动，也不会上传。

尚未选择图片

URL 解析

粘贴一条链接，拆出协议、域名、端口、路径和每个查询参数（参数值会自动解码）。也可以对任意文本做 URL 编码或解码。

—

日期计算

算两个日期隔多少天、中间有几个工作日，或者从某天往后（往前）推 N 天是哪一天。只算日期，不含时分秒。

—
—

JSON 与 CSV

JSON 得是对象数组（每项一条记录），转 CSV 时取所有字段的并集当表头。CSV 转 JSON 时第一行当表头，带引号的字段和换行都能正确解析。

进制转换

二进制、八进制、十进制、十六进制互转，用大整数运算，几十位也不会丢精度。十六进制大小写都认。

—

UUID / 随机 ID

用浏览器自带的加密随机数生成，符合 RFC 4122 的 v4 格式。短 ID 适合当订单号、文件名后缀这类不需要全局唯一的场合。

金额大写

把数字金额写成中文大写，报账、开票、写合同的时候用得上。四舍五入到分，最大支持到万亿。

—

所有工具都在本页内运行，不调用外部接口，也不保存你的输入。页面刷新即清空。
